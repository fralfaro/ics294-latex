\section{Introducción}

% Slide 1 - Introducción
\begin{frame}{Introducción}
    \begin{itemize}
        \item La multicolinealidad ocurre cuando dos o más variables explicativas en un modelo de regresión están altamente correlacionadas.
        \pause
        \item Cuando la dependencia es \textbf{exacta}, viola el supuesto de \emph{no multicolinealidad perfecta} del modelo clásico de regresión lineal (MCRL).
        \pause
        \item Cuando es solo \textbf{fuerte} (no exacta), el supuesto técnicamente se cumple, pero la \emph{precisión} de los coeficientes estimados se deteriora.
        \pause
        \item Distinguir ambos casos es clave: uno impide estimar, el otro solo dificulta interpretar.
    \end{itemize}
\end{frame}

% ====================================================================
\begin{frame}{El modelo y el supuesto}
\begin{block}{Modelo de regresión múltiple}
\[
y_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_k x_{ik} + u_i,\qquad i=1,\dots,n,
\]
en forma matricial $\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{u}$, con $\mathbf{X}$ de dimensión $n\times(k+1)$.
\end{block}

\pause

\begin{block}{Supuesto RLM.3 (No multicolinealidad perfecta)}
Ningún regresor es constante y \textbf{no existe una relación lineal exacta} entre los regresores. Equivale a que $\mathbf{X}$ tenga \emph{rango columna completo}, es decir, $\text{rango}(\mathbf{X})=k+1$, lo que garantiza que $\mathbf{X}'\mathbf{X}$ sea invertible.
\end{block}
\end{frame}

% ====================================================================
\begin{frame}{Dos tipos de multicolinealidad}
\begin{columns}
  \column{0.48\textwidth}
  \begin{alertblock}{Perfecta}
  Existe $\mathbf{a}\neq \mathbf{0}$ con $\mathbf{X}\mathbf{a}=\mathbf{0}$.
  \begin{itemize}
    \item $\mathbf{X}'\mathbf{X}$ es \textbf{singular}.
    \item $\hat{\boldsymbol{\beta}}$ \textbf{no está definido}.
    \item El modelo \textbf{no es identificable}.
  \end{itemize}
  \emph{Ejemplo:} incluir gasto en miles y en pesos; trampa de las variables dummy.
  \end{alertblock}

  \column{0.48\textwidth}
  \begin{block}{Imperfecta (alta)}
  Correlación fuerte pero \textbf{no exacta}.
  \begin{itemize}
    \item $\mathbf{X}'\mathbf{X}$ \textbf{sí} es invertible.
    \item MCO sigue siendo \textbf{insesgado y BLUE}.
    \item Pero las \textbf{varianzas se inflan}.
  \end{itemize}
  \emph{Ejemplo:} años de educación y experiencia laboral muy correlacionados.
  \end{block}
\end{columns}
\end{frame}

% ====================================================================
\section{Multicolinealidad perfecta}

\begin{frame}{Multicolinealidad perfecta: $\mathbf{X}'\mathbf{X}$ singular}
\begin{alertblock}{Proposición}
Si hay multicolinealidad perfecta, $\mathbf{X}$ no tiene rango columna completo, $\mathbf{X}'\mathbf{X}$ es singular y el estimador MCO $\hat{\boldsymbol{\beta}}=(\mathbf{X}'\mathbf{X})^{-1}\mathbf{X}'\mathbf{y}$ \textbf{no existe} (los coeficientes no son identificables).
\end{alertblock}

\pause

\begin{exampleblock}{Demostración (sketch)}
Suponga que existe $\mathbf{a}\neq\mathbf{0}$ tal que $\mathbf{X}\mathbf{a}=\mathbf{0}$ (una columna es combinación lineal exacta de las otras). Entonces
\[
(\mathbf{X}'\mathbf{X})\,\mathbf{a} = \mathbf{X}'(\mathbf{X}\mathbf{a}) = \mathbf{X}'\mathbf{0} = \mathbf{0},
\]
con $\mathbf{a}\neq\mathbf{0}$. Es decir, $\mathbf{X}'\mathbf{X}$ tiene un vector no nulo en su núcleo $\Rightarrow$ $\mathbf{X}'\mathbf{X}$ es \textbf{singular} (no invertible) y $\det(\mathbf{X}'\mathbf{X})=0$.
\pause

Como $(\mathbf{X}'\mathbf{X})^{-1}$ no existe, $\hat{\boldsymbol{\beta}}$ no está definido. Geométricamente: infinitas combinaciones de coeficientes ajustan los datos igual de bien. \hfill $\square$
\end{exampleblock}
\end{frame}

% ====================================================================
\begin{frame}{La ``trampa'' de las variables dummy}
\begin{block}{Caso típico de colinealidad perfecta}
Si una variable categórica con $m$ categorías se codifica con $m$ dummies \textbf{y} se incluye la constante, entonces
\[
D_1 + D_2 + \cdots + D_m = 1 \quad (\text{= columna de la constante}),
\]
una relación lineal \textbf{exacta}. El software arroja error o elimina una columna.
\end{block}

\pause

\begin{exampleblock}{Solución}
Omitir una categoría (la \emph{base}) o eliminar la constante. Con $m$ categorías se incluyen $m-1$ dummies. Esto \textbf{no} es multicolinealidad alta; es un error de especificación que se corrige reespecificando el modelo.
\end{exampleblock}
\end{frame}

\section{Multicolinealidad imperfecta y varianza}

% Slide 2 - Supuesto de No Multicolinealidad
\begin{frame}{Multicolinealidad imperfecta (alta)}
    \begin{itemize}
        \item En el MCRL se asume que no hay multicolinealidad \textbf{perfecta}; la correlación alta (pero no exacta) \emph{no} viola el supuesto.
        \pause
        \item Cuando las variables están altamente correlacionadas, el modelo tiene dificultad para distinguir los efectos individuales de cada variable.
        \pause
        \item Intuición: si $x_1$ y $x_2$ casi siempre se mueven juntas, los datos contienen poca información para separar $\beta_1$ de $\beta_2$.
        \pause
        \item Esto afecta la \textbf{precisión} (varianzas grandes) y la \textbf{estabilidad} de los resultados, no su insesgadez.
    \end{itemize}
\end{frame}

% ====================================================================
\begin{frame}[allowframebreaks]{Varianza del estimador MCO bajo colinealidad}
\begin{alertblock}{Teorema (Varianza de $\hat{\beta}_j$)}
Bajo los supuestos de Gauss-Markov, la varianza del estimador MCO del coeficiente $j$ en un modelo con $k$ regresores es
\[
\boxed{\;\text{Var}(\hat{\beta}_j) = \frac{\sigma^2}{\text{SCT}_j\,(1 - R_j^2)}\;}
\]
donde $\text{SCT}_j=\sum_{i=1}^n (x_{ij}-\bar{x}_j)^2$ y $R_j^2$ es el $R^2$ de la \emph{regresión auxiliar} de $x_j$ sobre todos los demás regresores.
\end{alertblock}

\framebreak

\begin{exampleblock}{Demostración (sketch, caso de dos regresores)}
Sea el modelo $y_i=\beta_0+\beta_1 x_{i1}+\beta_2 x_{i2}+u_i$. Por el teorema de Frisch-Waugh-Lovell, $\hat{\beta}_1$ se obtiene regresando $y$ sobre los \textbf{residuos} $\hat{r}_{i1}$ de regresar $x_1$ sobre $x_2$ (y la constante):
\[
\hat{\beta}_1 = \frac{\sum_i \hat{r}_{i1}\, y_i}{\sum_i \hat{r}_{i1}^2}.
\]
\pause
Aplicando $\text{Var}(\cdot\mid \mathbf{X})$ y usando $\text{Var}(u_i\mid\mathbf{X})=\sigma^2$ y $\text{Cov}(u_i,u_j)=0$:
\[
\text{Var}(\hat{\beta}_1\mid\mathbf{X}) = \frac{\sigma^2}{\sum_i \hat{r}_{i1}^2}.
\]
\framebreak
Ahora bien, $\sum_i \hat{r}_{i1}^2 = \text{SCR}_1$ es la suma de cuadrados de residuos de la regresión auxiliar de $x_1$ sobre $x_2$. Por la descomposición $R_1^2 = 1 - \text{SCR}_1/\text{SCT}_1$:
\[
\sum_i \hat{r}_{i1}^2 = \text{SCT}_1\,(1 - R_1^2).
\]
\pause
Sustituyendo:
\[
\text{Var}(\hat{\beta}_1\mid\mathbf{X}) = \frac{\sigma^2}{\text{SCT}_1\,(1 - R_1^2)}.
\]
El argumento general (con $k$ regresores) es idéntico reemplazando $R_1^2$ por $R_j^2$ de la auxiliar de $x_j$ sobre los demás. \hfill $\square$
\end{exampleblock}

\framebreak

\begin{block}{Lectura del resultado}
\[
\text{Var}(\hat{\beta}_j) = \frac{\sigma^2}{\text{SCT}_j} \cdot \underbrace{\frac{1}{1-R_j^2}}_{\text{VIF}_j}.
\]
\begin{itemize}
    \item Si $x_j$ está poco relacionada con los demás regresores, $R_j^2\approx 0$ y $\text{VIF}_j\approx 1$ (sin inflación).
    \item A medida que $R_j^2 \to 1$ (colinealidad creciente), $\text{VIF}_j \to \infty$ y la varianza \textbf{explota}.
    \item En el límite $R_j^2=1$ (colinealidad \emph{perfecta}) la varianza es infinita: el coeficiente no es identificable.
\end{itemize}
\end{block}
\end{frame}

% ====================================================================
\begin{frame}{Punto clave: NO se viola Gauss-Markov}
\begin{alertblock}{Aclaración fundamental}
La multicolinealidad alta (imperfecta) \textbf{no viola} ningún supuesto de Gauss-Markov. El estimador MCO sigue siendo \textbf{insesgado}, \textbf{consistente} y \textbf{BLUE} (de mínima varianza entre los lineales insesgados).
\end{alertblock}

\pause

\begin{exampleblock}{¿Entonces cuál es el problema?}
\begin{itemize}
    \item El problema es de \textbf{precisión}, no de \textbf{sesgo}: $\mathbb{E}[\hat{\beta}_j]=\beta_j$, pero $\text{Var}(\hat{\beta}_j)$ es grande.
    \item MCO sigue dando la \emph{menor} varianza posible entre los estimadores lineales insesgados; lo que ocurre es que \textbf{esa mínima ya es grande} porque los datos contienen poca información para separar los efectos.
    \item No se ``corrige'' como una violación de supuestos: se mitiga aportando más información (más datos o restricciones).
\end{itemize}
\end{exampleblock}
\end{frame}

\section{Efectos prácticos}

% Slide 3 - Efectos de la Multicolinealidad
\begin{frame}{Efectos de la Multicolinealidad (alta)}
    \begin{itemize}
        \item \textbf{Inflación de los errores estándar:} los coeficientes se estiman con menor precisión; $\text{ee}(\hat{\beta}_j)=\sqrt{\text{Var}(\hat{\beta}_j)}$ crece con el VIF.
        \pause
        \item \textbf{$t$ pequeños pero $R^2$ alto:} cada $t_j=\hat{\beta}_j/\text{ee}(\hat{\beta}_j)$ puede ser no significativo, ¡aunque el $R^2$ global y el test $F$ conjunto sean altos!
        \pause
        \item \textbf{Inestabilidad / signos raros:} pequeñas variaciones en los datos pueden causar grandes cambios en los coeficientes, e incluso cambiar su signo respecto a la teoría económica.
        \pause
        \item \textbf{Sensibilidad a la muestra:} agregar o quitar pocas observaciones altera notoriamente las estimaciones.
        \pause
        \item \textbf{Dificultad de interpretación:} no se pueden separar los efectos individuales ``ceteris paribus''.
    \end{itemize}
\end{frame}

% ====================================================================
\begin{frame}{Síntoma clásico: $t$ bajos con $R^2$ alto}
\begin{block}{Señal de alerta}
Si la regresión tiene un $R^2$ alto y un test $F$ global muy significativo, \textbf{pero} ningún (o casi ningún) coeficiente individual es significativo según su prueba $t$, sospeche de \textbf{multicolinealidad}.
\end{block}

\pause

\begin{exampleblock}{Intuición}
El conjunto de regresores explica bien a $y$ ($R^2$ alto, $F$ significativo), pero están tan correlacionados entre sí que es imposible atribuir el efecto a un regresor \emph{en particular} (cada $t$ bajo). Es la firma de varianzas infladas.
\end{exampleblock}
\end{frame}

\section{Detección}

\begin{frame}{Detección: Matriz de Correlación}
    \begin{itemize}
        \item La \textbf{matriz de correlación} de las variables explicativas permite identificar relaciones lineales fuertes entre pares de variables.
        \pause
        \item Valores cercanos a \(\pm 1\) entre dos variables indican posible multicolinealidad.
        \pause
        \item \textbf{Limitación:} solo detecta colinealidad entre \emph{pares}; puede haber multicolinealidad entre \emph{combinaciones lineales} de varias variables sin que ningún par tenga correlación extrema.
    \end{itemize}
\pause
\[
\mathbf{R}=
\begin{bmatrix}
1 & 0.90 & 0.85 \\
0.90 & 1 & 0.70 \\
0.85 & 0.70 & 1
\end{bmatrix}
\;\Rightarrow\; \text{pares HES--ASIST (0.90) y HES--TE (0.85) sospechosos.}
\]
\end{frame}

% Slide 4 - Detección de la Multicolinealidad: VIF
\begin{frame}{Detección: Factor de Inflación de la Varianza (VIF)}
    \begin{itemize}
        \item El \textbf{Factor de Inflación de la Varianza} (VIF) mide cuánto aumenta la varianza de un coeficiente debido a la multicolinealidad.
        \item Para una variable \(X_j\):
        \[
        \text{VIF}(X_j) = \frac{1}{1 - R_j^2},
        \]
        donde \(R_j^2\) es el $R^2$ de la regresión auxiliar de \(X_j\) sobre las demás variables explicativas.
        \pause
        \item Interpretación: $\text{Var}(\hat{\beta}_j) = \dfrac{\sigma^2}{\text{SCT}_j}\cdot \text{VIF}(X_j)$.
        \item Reglas prácticas: $\text{VIF} > 10$ (equiv. $R_j^2>0.9$) indica multicolinealidad \textbf{severa}; $\text{VIF}>5$ amerita atención.
        \item La \textbf{tolerancia} $=1/\text{VIF}=1-R_j^2$ es la medida recíproca.
    \end{itemize}
\end{frame}

% Slide 6 - Número de condición
\begin{frame}{Detección: Número de Condición}
    \begin{itemize}
        \item La \textbf{descomposición en valores propios} (eigenvalores) de $\mathbf{X}'\mathbf{X}$ (sobre variables estandarizadas) permite detectar multicolinealidad.
        \pause
        \item El \textbf{número de condición} es la raíz de la razón entre el mayor y el menor eigenvalor:
        \[
        \kappa = \sqrt{\frac{\lambda_{\max}}{\lambda_{\min}}}.
        \]
        \pause
        \item Reglas prácticas: $\kappa$ entre 10 y 30 sugiere multicolinealidad \emph{moderada}; $\kappa > 30$ indica multicolinealidad \textbf{severa}.
        \item Ventaja: captura colinealidad entre \emph{combinaciones} de varias variables, no solo pares.
    \end{itemize}
\end{frame}

\section{Remedios}

% Slide 7 - Recomendaciones para Mitigar la Multicolinealidad
\begin{frame}{Remedios para la Multicolinealidad}
    \begin{itemize}
        \item \textbf{Aumentar el tamaño de la muestra:} más datos elevan $\text{SCT}_j$ y aportan información que reduce $\text{Var}(\hat{\beta}_j)$. Suele ser el remedio ``correcto'' (ataca la raíz: falta de información).
        \pause
        \item \textbf{Eliminar o combinar variables:} remover una de las variables casi redundantes, o combinarlas en un índice (cuidado con el \emph{sesgo de variable omitida}).
        \pause
        \item \textbf{Componentes principales (PCA):} reemplazar los regresores correlacionados por componentes ortogonales.
        \pause
        \item \textbf{Regresión \textit{ridge} (mención):} introduce un pequeño sesgo a cambio de reducir mucho la varianza, $\hat{\boldsymbol{\beta}}_{\text{ridge}}=(\mathbf{X}'\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}'\mathbf{y}$, estabilizando la inversión.
        \pause
        \item \textbf{Transformar variables:} centrar/estandarizar o usar diferencias/logaritmos puede reducir la colinealidad en ciertos casos.
    \end{itemize}
\end{frame}

% ====================================================================
\begin{frame}{¿Cuándo NO hacer nada?}
\begin{block}{Una decisión muy importante}
La multicolinealidad \textbf{no siempre} requiere acción:
\begin{itemize}
    \item Si el objetivo es \textbf{predecir} (no interpretar coeficientes individuales), la multicolinealidad no es un problema: MCO sigue siendo insesgado y el modelo predice bien.
    \item Si los coeficientes de interés \emph{sí} son significativos a pesar de la colinealidad, no hay nada que corregir.
    \item ``Curar'' la colinealidad eliminando variables puede introducir \textbf{sesgo de variable omitida}, un mal peor.
\end{itemize}
\end{block}
\end{frame}

\section{Ejercicios resueltos}

% --- Ejercicio resuelto 1 (adaptado de Certamen 3 RP - Tributario) ---
\begin{frame}{Ejercicio Resuelto 1}
\begin{block}{Ejercicio 1 (VIF y diagnóstico)}
Se modela el rendimiento académico de estudiantes de la UTFSM en función de tres variables: horas de estudio semanales (HES), asistencia a clases (ASIST) y tiempo efectivo de estudio (TE). La matriz de correlación entre regresores es
\[
\mathbf{R}=\begin{bmatrix} 1 & 0.90 & 0.85 \\ 0.90 & 1 & 0.70 \\ 0.85 & 0.70 & 1\end{bmatrix},
\]
y las regresiones auxiliares dan $R^2_{\text{HES}}=0.91$, $R^2_{\text{ASIST}}=0.75$, $R^2_{\text{TE}}=0.80$. Calcule los VIF e indique si hay multicolinealidad severa.
\end{block}
\end{frame}

\begin{frame}{Ejercicio Resuelto 1 — Solución}
\begin{exampleblock}{Solución}
\textbf{Paso 1.} Aplicar $\text{VIF}_j=1/(1-R_j^2)$:
\[
\text{VIF}_{\text{HES}}=\frac{1}{1-0.91}=11.1,\quad
\text{VIF}_{\text{ASIST}}=\frac{1}{1-0.75}=4,\quad
\text{VIF}_{\text{TE}}=\frac{1}{1-0.80}=5.
\]
\textbf{Paso 2.} Comparar con el umbral $\text{VIF}>10$:
\begin{itemize}
    \item HES tiene $\text{VIF}=11.1>10 \Rightarrow$ \textbf{multicolinealidad severa} sobre HES.
    \item ASIST y TE ($4$ y $5$) están bajo el umbral; atención moderada.
\end{itemize}
\textbf{Paso 3. Remedio.} Eliminar HES del modelo (queda casi totalmente explicada por ASIST y TE), reduciendo la varianza de los estimadores y facilitando la interpretación. Alternativa: combinar HES y TE en un índice de esfuerzo, o recolectar más datos.
\end{exampleblock}
\end{frame}

% --- Ejercicio resuelto 2 (datos chilenos: vivienda) ---
\begin{frame}{Ejercicio Resuelto 2}
\begin{block}{Ejercicio 2 (inflación de la varianza)}
Se estima el precio de viviendas en Santiago (millones de CLP) sobre la superficie construida $x_1$ ($\text{m}^2$) y el número de habitaciones $x_2$. Estas variables están muy correlacionadas. Se dispone de:
\[
\hat{\sigma}^2 = 400,\quad \text{SCT}_1=\sum (x_{i1}-\bar{x}_1)^2 = 10\,000,\quad R_1^2 = 0.92.
\]
(a) Calcule $\text{Var}(\hat{\beta}_1)$ y su error estándar. (b) Compárelo con el caso hipotético sin colinealidad ($R_1^2=0$). (c) Concluya.
\end{block}
\end{frame}

\begin{frame}{Ejercicio Resuelto 2 — Solución}
\begin{exampleblock}{Solución}
\textbf{(a)} Con la fórmula $\text{Var}(\hat{\beta}_1)=\dfrac{\sigma^2}{\text{SCT}_1(1-R_1^2)}$:
\[
\text{Var}(\hat{\beta}_1)=\frac{400}{10\,000\,(1-0.92)}=\frac{400}{800}=0.5,\qquad \text{ee}(\hat{\beta}_1)=\sqrt{0.5}\approx 0.707.
\]
\pause
\textbf{(b)} Sin colinealidad ($R_1^2=0$):
\[
\text{Var}^{\text{no col}}(\hat{\beta}_1)=\frac{400}{10\,000\,(1)}=0.04,\qquad \text{ee}\approx 0.20.
\]
El $\text{VIF}=1/(1-0.92)=12.5$: la varianza se infló \textbf{12.5 veces} y el error estándar $\sqrt{12.5}\approx 3.5$ veces.
\pause
\textbf{(c)} La colinealidad entre superficie y número de habitaciones triplica con creces el error estándar: el coeficiente de $x_1$ podría salir no significativo aunque el efecto sea real. MCO sigue insesgado; solo perdió precisión.
\end{exampleblock}
\end{frame}

\section{Ejemplo aplicado}

\begin{frame}[fragile]{Ejemplo aplicado: VIF en Python}
\begin{exampleblock}{Cálculo del VIF con statsmodels (datos de salarios, Chile)}
\begin{verbatim}
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence \
     import variance_inflation_factor as vif

datos = pd.read_csv("casen_salarios.csv")

\section{Resumen}

\begin{frame}{Resumen}

\begin{block}{Puntos Clave de la Clase 18}
\begin{enumerate}
    \item \textbf{Perfecta vs. imperfecta:} la perfecta hace $\mathbf{X}'\mathbf{X}$ singular y $\hat{\boldsymbol{\beta}}$ no identificable; la alta solo infla varianzas.
    \item La varianza clave es $\text{Var}(\hat{\beta}_j)=\dfrac{\sigma^2}{\text{SCT}_j(1-R_j^2)}$: cuando $R_j^2\to 1$, $\text{VIF}_j=\frac{1}{1-R_j^2}\to\infty$.
    \item La multicolinealidad alta \textbf{NO viola} Gauss-Markov: MCO sigue insesgado y BLUE; el problema es de \emph{precisión}, no de \emph{sesgo}.
    \item Detección: matriz de correlación (solo pares), \textbf{VIF} ($>10$ severo) y número de condición ($\kappa>30$ severo).
    \item Remedios: más datos, eliminar/combinar variables, PCA, \textit{ridge}; a veces lo correcto es no hacer nada (predicción).
\end{enumerate}
\end{block}

% Slide 8 - Conclusiones
\begin{frame}{Conclusiones}
    \begin{itemize}
        \item La multicolinealidad no afecta la validez del modelo para \textbf{predicción}, pero sí la interpretación y estabilidad de los coeficientes individuales.
        \item Es importante diagnosticar (VIF, correlación, número de condición) antes de interpretar coeficientes ``ceteris paribus''.
        \item Las técnicas de mitigación reducen su impacto, pero deben sopesarse contra el riesgo de sesgo de variable omitida.
    \end{itemize}
\end{frame}
