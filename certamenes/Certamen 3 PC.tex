\section{Preguntas Cortas (30 Puntos)}

\begin{enumerate}

\item (10 Puntos) ¿En qué casos, y por qué motivos, conviene transformar las variables a primeras diferencias cuando se trabaja con series de tiempo?
\\
\textbf{Solución}
\\
Se debe aplicar primeras diferencias cuando nos encontramos con que los valores en niveles siguen una caminata aleatoria, esto por que el valor no tiene media constante y su varianza crece en el tiempo. Estimar el modelo por MCO en niveles generará correlaciones espurias y no tendrá estacionaridad, por lo que se debe transformar a primeras diferencias para obtener una serie estacionaria y así encontrar estimadores MCO insesgados.

\item (10 Puntos) Defina claramente las dos condiciones que debe cumplir una variable instrumental para ser considerada válida e indique qué problema aparece si se viola cada una de ellas.  \\
\textbf{Solución} 
\\
\begin{itemize}
  \item {Relevancia}: el instrumento $Z$ debe estar correlacionado con la variable endógena $X$, 
        es decir, $\operatorname{Cov}(Z,X)\neq 0$.
  \item {Exogeneidad}: $Z$ no debe correlacionarse con el error 
        estructural $u$, esto es, $\operatorname{Cov}(Z,u)=0$.
\end{itemize}

\textbf{Consecuencias de las violaciones}
\begin{itemize}
  \item \emph{Instrumento débil} (falla de relevancia): el estimador IV se sesga hacia MCO y sus 
        varianzas se inflan, debilitando la inferencia.
  \item \emph{Instrumento inválido} (falla de exogeneidad): el estimador IV se vuelve inconsistente; 
        el sesgo puede superar al de MCO.
\end{itemize}

\item (10 Puntos) Compare el test de White (versión completa) con el test de Breusch-Pagan y mencione una ventaja y una desventaja clave de emplear el test de White.\\
\textbf{Solución}
\\
\textbf{Ventaja principal del test de White:}
Detecta heterocedasticidad de prácticamente cualquier forma porque incluye términos cuadráticos e interacciones de los regresores; no necesita suponer un patrón particular para la varianza condicional.
\\
\textbf{Desventaja principal del test de White:}
Al agregar muchos términos en la regresión auxiliar consume grados de libertad y, en muestras pequeñas, puede perder potencia estadística frente al test de Breusch-Pagan, que es más parsimonioso.

\end{enumerate}

\section{Ejercicios (70 Puntos)}

\begin{enumerate}

\item (25 Puntos) Se dispone de una muestra de 350 observaciones con la cual se estimó el siguiente modelo de regresión lineal múltiple:
$$Salario_i = \beta_0 + \beta_1\,\textit{Educ}_i + \beta_2\,\textit{Exper}_i + u_i$$
Se desea contrastar el supuesto de heterocedasticidad y, para ello, se aplicará el método de White simplificado.
\begin{enumerate}
    \item (10 Puntos) Plantee la regresión auxiliar para el método de White simplificado.\\
    \textbf{Solución}\\
    $$\hat{u}_i^{\,2} = \alpha_0 + \alpha_1 \hat{Salario}_i + \alpha_2 \hat{Salario}_i^{\,2} + v_i$$
    
    \item (5 puntos) Formule la hipótesis nula y la hipótesis alternativa para contrastar la presencia de heterocedasticidad.\\
    \textbf{Solución}\\
    $$H_0:\ \alpha_1 = \alpha_2 = 0$$
    $$H_1:\ \alpha_1 \neq 0 \ \text{o}\ \alpha_2 \neq 0$$
    
    \item (10 Puntos) Si el $R^2$ de la regresión auxiliar es $0.14$, contraste, al 5\% de significación, la existencia de heterocedasticidad mediante el estadístico del multiplicador de Lagrange.\\
    \textbf{Solución}\\
    $$LM \;=\; n R^2_{\text{aux}} \;=\; 350 \times 0.14 \;=\; 49 \;\sim\; \chi^2_{(2)}$$
    El valor crítico de $\chi^2_{(2)}$ al 5\% es $5.991$. Como
    $$LM \;>\; \chi^2_{0.95,\,2} \;\; \Longrightarrow \;\; 49 \;>\; 5.991,$$
    se rechaza la hipótesis nula y se concluye que existe heterocedasticidad.
\end{enumerate}

\item (20 Puntos) Considere el siguiente modelo de regresión lineal  de los puntajes de una prueba para la selección universitaria.
$$Puntaje_i = \beta_0 + \beta_1 IQ_i + \beta_2 Edad_i + \beta_3 HE$$
Siendo $IQ$ el coeficiente intelectual, la $Edad$ es la edad del estudiante y $HE$ las horas de estudio. Se sospecha que la regresión presenta multicolinealidad en la variable $Edad$. 

\begin{enumerate}
    \item  (10 Puntos) Plantee la regresión auxiliar que nos permite encontrar multicolinealidad en la variable $Edad$ usando VIF. \\
\textbf{Solución}
$$Edad_i = \alpha_0+ \alpha_1 IQ_i + \alpha_2 HE_i + v_i$$

    \item (10 Puntos) Si $R^2_{Edad} = 0.91$, calcule VIF y concluya si existe multicolinealidad sobre esta variable.

$$VIF = \frac{1}{1-R^2_{Edad}} = \frac{1}{1-0.91}=11.11$$
Como $VIF >10$ se puede decir que existe multicolinealidad sobre la variable $Edad$
\end{enumerate}
