\section{Preguntas Cortas }

\begin{enumerate}

\item  ¿En qué casos, y por qué motivos, conviene transformar las variables a primeras diferencias cuando se trabaja con series de tiempo?
\\
{\color{blue}\textbf{Solución}
\\
Se debe aplicar primeras diferencias cuando nos encontramos con que los valores en niveles siguen una caminata aleatoria, esto por que el valor no tiene media constante y su varianza crece en el tiempo. Estimar el modelo por MCO en niveles generará correlaciones espurias y no tendrá estacionaridad, por lo que se debe transformar a primeras diferencias para obtener una serie estacionaria y así encontrar estimadores MCO insesgados.}

\item  Defina claramente las dos condiciones que debe cumplir una variable instrumental para ser considerada válida e indique qué problema aparece si se viola cada una de ellas.  \\
{\color{blue}\textbf{Solución} 
\\
 \begin{enumerate}
        \item {\color{blue}\textbf{Relevancia:} }$\operatorname{Cov}(X, Z) \neq 0$. La variable $Z$ afecta a $X$. Como observamos $Z$ y $X$, este supuesto es testeable.
        \item  {\color{blue}\textbf{Exogeneidad o restricci\'on de exclusi\'on:}} $\operatorname{Cov}(Z, U)=0$. 
        \begin{itemize}
            \item El instrumento no se correlaciona con el error.
            \item $E[Y \mid X]=E[Y \mid X, Z]$: el instrumento $Z$ no afecta directamente a $Y$, s\'olo lo hace a trav\'es de su efecto en $X$.
        \end{itemize}
    \end{enumerate}

\textbf{Consecuencias de las violaciones}
\begin{itemize}
  \item \emph{Instrumento débil} (falla de relevancia): el estimador IV se sesga hacia MCO y sus 
        varianzas se inflan, debilitando la inferencia.
  \item \emph{Instrumento inválido} (falla de exogeneidad): el estimador IV se vuelve inconsistente; 
        el sesgo puede superar al de MCO.
\end{itemize}}

\item  Compare el test de White (versión completa) con el test de Breusch-Pagan y mencione una ventaja y una desventaja clave de emplear el test de White.\\
{\color{blue}\textbf{Solución}

Regresion auxiliar test de  Breusch-Pagan: 
\[
\hat u_i^{2} = \delta_0 + \delta_1 x_{1i} + \dots + \delta_k x_{ki} + v_i
\]

Regresion auxiliar test de  White (versión completa): 

\[\hat u_t^{2}
= \alpha_0
+ \alpha_1 x_{1t}
+ \alpha_2 x_{2t}
+ \dots
+ \alpha_k x_{kt}
+ \alpha_{k+1} x_{1t}^2
+ \alpha_{k+2} x_{2t}^2
+ \dots
+ \alpha_{2k} x_{kt}^2
+ \text{(términos de interacción)}
+ v_t
\]

\\
\textbf{Ventaja principal del test de White:}
Detecta heterocedasticidad de prácticamente cualquier forma porque incluye términos cuadráticos e interacciones de los regresores; no necesita suponer un patrón particular para la varianza condicional.
\\
\textbf{Desventaja principal del test de White:}
Al agregar muchos términos en la regresión auxiliar consume grados de libertad y, en muestras pequeñas, puede perder potencia estadística frente al test de Breusch-Pagan, que es más parsimonioso.}

\end{enumerate}

\section{Ejercicios }

\begin{enumerate}

\item Se dispone de una muestra de 350 observaciones con la cual se estimó el siguiente modelo de regresión lineal múltiple:
$$Salario_i = \beta_0 + \beta_1\,\textit{Educ}_i + \beta_2\,\textit{Exper}_i + u_i$$
Se desea contrastar el supuesto de heterocedasticidad y, para ello, se aplicará el método de White simplificado.
\begin{enumerate}
    \item  Plantee la regresión auxiliar para el método de White simplificado.\\
   {\color{blue} \textbf{Solución}\\
    $$\hat{u}_i^{\,2} = \alpha_0 + \alpha_1 \hat{Salario}_i + \alpha_2 \hat{Salario}_i^{\,2} + v_i$$}
    
    \item  Formule la hipótesis nula y la hipótesis alternativa para contrastar la presencia de heterocedasticidad.\\
    {\color{blue}\textbf{Solución}\\
    $$H_0:\ \alpha_1 = \alpha_2 = 0$$
    $$H_1:\ \alpha_1 \neq 0 \ \text{o}\ \alpha_2 \neq 0$$}
    
    \item  Si el $R^2$ de la regresión auxiliar es $0.14$, contraste, al 5\% de significación, la existencia de heterocedasticidad mediante el estadístico del multiplicador de Lagrange.\\
    {\color{blue}\textbf{Solución}\\
    $$LM \;=\; n R^2_{\text{aux}} \;=\; 350 \times 0.14 \;=\; 49 \;\sim\; \chi^2_{(2)}$$
    El valor crítico de $\chi^2_{(2)}$ al 5\% es $5.991$. Como
    $$LM \;>\; \chi^2_{0.95,\,2} \;\; \Longrightarrow \;\; 49 \;>\; 5.991,$$
    se rechaza la hipótesis nula y se concluye que existe heterocedasticidad.}
\end{enumerate}

\item  Considere el siguiente modelo de regresión lineal  de los puntajes de una prueba para la selección universitaria.
$$Puntaje_i = \beta_0 + \beta_1 IQ_i + \beta_2 Edad_i + \beta_3 HE+u_i$$
Siendo $IQ$ el coeficiente intelectual, la $Edad$ es la edad del estudiante y $HE$ las horas de estudio. Se sospecha que la regresión presenta multicolinealidad en la variable $HE$. 

\begin{enumerate}
    \item   Plantee la regresión auxiliar que nos permite encontrar multicolinealidad en la variable $HE$ usando VIF. \\
{\color{blue}\textbf{Solución}
$$HE_i = \alpha_0+ \alpha_1 IQ_i + \alpha_2 edad_i + v_i$$}

    \item  Si $R^2_{HE} = 0.91$, calcule VIF y concluya si existe multicolinealidad sobre esta variable.

{\color{blue}$$VIF = \frac{1}{1-R^2_{HE}} = \frac{1}{1-0.91}=11.11$$
Como $VIF >10$ se puede decir que existe multicolinealidad sobre la variable $HE$}
\end{enumerate}
