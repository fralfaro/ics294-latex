\section{Ejercicios}
\begin{enumerate}


\item Una empresa de ventas de neumaticos esta realizando un modelo de regresión lineal multiple para predecir las ventas del proximo año, para esto han utilizado el siguiente modelo:
$$Ventas = \beta_0 + \beta_1ADV + \beta_2PROD+\beta_3CLI + u$$
Donde $ADV$ son el gasto en propagandas, $PROD$ la producción del año anterior y $CLI$ la cantidad de clientes. Se sospecha que estas ventas son diferentes por Zonas geograficas, por lo que se estima un modelo para cada Zona: NORTE, CENTRO y SUR, obteniendo: 
$$Ventas_{g} = \beta_{0g} + \beta_{1g}ADV + \beta_{2g}PROD+\beta_{3g}CLI + u$$
para $g \in {(NORTE,CENTRO,SUR)}$. Usando como datos las 50 tiendas que tienen a nivel nacional se tienen los siguientes resultados:
\begin{center}
    \begin{tabular}{|c|c|}
    \hline
        Modelo & SSR \\
        \hline
        Base & 250 \\
        \hline
        Norte & 80 \\
        \hline
        Centro & 70 \\
        \hline
        Sur & 50 \\
        \hline
    \end{tabular}
\end{center}
Testee, con una significancia del 5\%, si las ventas por Zonas son diferentes. ($F_{0.95,(8,38)}=2.19$)
\\
\textbf{Solución}
\\
\textbf{Test de Chow por Zonas (NORTE, CENTRO, SUR).}

\begin{itemize}
\item Modelo base (restringido, pooled): 
\[
Ventas = \beta_0 + \beta_1 ADV + \beta_2 PROD + \beta_3 CLI + u,
\]
con $k=3$ regresores (más constante).

\item Modelos por grupo (no restringidos):
\[
Ventas_g = \beta_{0g} + \beta_{1g} ADV + \beta_{2g} PROD + \beta_{3g} CLI + u,\quad g\in\{\text{NORTE, CENTRO, SUR}\}.
\]

\item Datos: $n=50$, $G=3$. 
SSR restringido (base): $SSR_r=250$. 
SSR por grupos: $SSR_{\text{Norte}}=80$, $SSR_{\text{Centro}}=70$, $SSR_{\text{Sur}}=50$.
\[
SSR_{ur}=80+70+50=200.
\]

\item Estadístico de prueba:
\[
F=\frac{(SSR_r-SSR_{ur})/((G-1)(k+1))}{SSR_{ur}/(n-G(k+1))}
=\frac{(250-200)/( (3-1)(3+1))}{200/(50-3(3+1))}
=\frac{50/8}{200/38}
=\frac{6.25}{5.2632}\approx 1.19.
\]

\item Grados de libertad: 
\[
df_1=(G-1)(k+1)=(3-1)\cdot 4=8,\qquad 
df_2=n-G(k+1)=50-3\cdot 4=38.
\]

\item Regla de decisión (5\%): 
\[
F_{crítico}(0.95;8,38)=2.19.
\]
Como $F_{\text{obs}}=1.19<2.19$, \textbf{no se rechaza} $H_0$.

\item \textbf{Conclusión:} al 5\% de significancia no hay evidencia estadística de que los parámetros del modelo difieran entre las zonas NORTE, CENTRO y SUR; el modelo común (pooled) es adecuado.
\end{itemize}



\item Se tiene un modelo del tipo:
$$y = \beta_0 + \beta_1x_1 + \beta_2x_2+\beta_3x_3 + u$$
pero se ha identificado dos grupos, por lo que se plantea un modelo separado para cada grupo:
$$y_g = \beta_{0g} + \beta_{1g}x_1 + \beta_{2g}x_2+\beta_{3g}x_3 + u_g$$
con $g\in {1,2}$, obteniendo los siguentes resultados desde una muestra de 150 datos:
\begin{center}
    \begin{tabular}{|c|c|}
    \hline
        Modelo & SSR \\
        \hline
        Base & 300 \\
        \hline
        1 & 155 \\
        \hline
        2 & 130 \\
        \hline
    \end{tabular}
\end{center}
¿Existen diferencias en y para cada grupo? Use una significancia del 5\%. ($F_{0.95,(4,142)}=2.44$)

\textbf{Solución}

Eso se resulve con el test de chow, siendo el estadistico igual a 
$$F = \frac{SSR_r-SSR_{ur}}{SSR_{ur}}\frac{n-G(k+1)}{(G-1)(k+1)}=\frac{300-285}{285}\frac{142}{4}=1.86$$
Como $1.86<2.44$ no se rechaza $H_0$ y podriamos decir que no hay diferencia entre los grupos.



\item Considere el modelo de regresión lineal, realizado con 254 datos:
\[
y_i \;=\; \beta_0 \;+\; \beta_1 x_i \;+\; \beta_2 D_i \;+\; \beta_3 (D_i x_i) \;+\; u_i,
\]
donde
\begin{itemize}
  \item $x_i$ es una variable continua,
  \item $D_i$ es una \emph{dummy} que vale $1$ si la observación pertenece al grupo $A$ y $0$ si pertenece al grupo $B$,
  \item $u_i$ es el término de error con $E[u_i \mid x_i,D_i]=0$.
\end{itemize}

\begin{enumerate}
  \item[(a)] Determine la pendiente $\partial y / \partial x$ para cada grupo ($D=0$ y $D=1$).
  \item[(b)] Interprete el coeficiente $\beta_3$ en términos de la diferencia entre grupos.
  \item[(c)] Se sospecha que no hay diferencias entre los grupos. Plantee el test de hipótesis que testea que no hay diferencia entre grupos.
  \item[(d)] Se sabe que el modelo completo tiene un $R^2=0.75$ y el modelo reducido, para este test, un $R^2=0.67$. ¿Hay diferencias entre los grupos con significancia del 5\%?
\end{enumerate}


% --- (Opcional) Solución resumida ------------------------------------------
\textbf{solución}
\begin{enumerate}
  \item[(a)] 
    \[
      \left.\frac{\partial y}{\partial x}\right|_{D=0} = \beta_1, 
      \qquad
      \left.\frac{\partial y}{\partial x}\right|_{D=1} = \beta_1 + \beta_3.
    \]
  \item[(b)] El parámetro $\beta_3$ mide \emph{cuánto varía} la pendiente de $x$ entre los grupos.  
        Si $\beta_3 \neq 0$, el impacto de $x$ sobre $y$ depende de pertenecer al grupo $A$ ($D=1$) o al grupo $B$ ($D=0$).
  \item[(c)] Lo que se desea testear es que los estimadores asociados a la dummy, son ceros.
  $$H_0:\beta_2=\beta_3=0$$
  $$H_1 : \beta_2 \neq 0 \ ó \ \beta_3 \neq 0$$

  \item[(d)] para testear lo anterior debemos aplicar test F siendo:
  $$F_{est} = \frac{0.75-0.67}{1-0.75}\frac{254-3-1}{2}=40$$
  El $F_{5\%,2,250}=3.03$
y como $F_{est}>F_{critico}$ se rechaza la hipotesis nula, y si hay diferencias entre los grupos.
\end{enumerate}

\end{enumerate}
