  \item[c)] (3 puntos) ¿Qué métodos pueden utilizarse para corregir o mitigar este problema?
\end{enumerate}



{\color{blue}  \textbf{a) Interpretación del p-valor del test de Breusch--Pagan}

El test de Breusch--Pagan contrasta la hipótesis nula:

\[
H_0: \operatorname{Var}(\varepsilon_i)=\sigma^2 \quad \text{(homocedasticidad)}
\]

contra la alternativa:

\[
H_1: \operatorname{Var}(\varepsilon_i)=\sigma_i^2  \quad \text{(heterocedasticidad)}
\]

donde $z_i$ son variables explicativas o funciones de ellas.

En la práctica, el test se implementa estimando la siguiente \textit{ecuación auxiliar}:

\[
\hat{u}_i^2 = \gamma_0 + \gamma_1 x_{1i} + \gamma_2 x_{2i} + \cdots + \gamma_k x_{ki} + v_i ,
\]

donde $\hat{u}_i$ son los residuos del modelo original. Bajo $H_0$, se tiene que:

\[
\gamma_1 = \gamma_2 = \cdots = \gamma_k = 0.
\]

El estadístico del test se construye mediante:

\[
LM = n R^2_{\text{aux}},
\]

que bajo $H_0$ se distribuye asintóticamente como $\chi^2_k$.

(Con la siguiente parte  es suficiente para obtener todo el puntaje)

Dado que el p-valor obtenido es $0.004$, menor a niveles de significancia comunes (1\%, 5\%), se rechaza $H_0$. Por lo tanto, existe evidencia estadística de heterocedasticidad y el supuesto de varianza constante no se cumple en el modelo.


\textbf{b) Efectos de la heterocedasticidad}

La heterocedasticidad no afecta la insesgadez de los estimadores OLS, pero sí altera sus propiedades de eficiencia y la validez de la inferencia:

\begin{itemize}
    \item Los errores estándar OLS se vuelven \textit{inconsistentes}, pudiendo estar subestimados o sobrestimados.
    \item Como consecuencia, los estadísticos $t$ y $F$ son incorrectos.
    \item Los intervalos de confianza pueden ser demasiado estrechos o demasiado amplios.
    \item Se pueden cometer errores en pruebas de significancia: falsos positivos o falsos negativos.
\end{itemize}

Por ello, la heterocedasticidad compromete la validez de la inferencia estadística basada en el modelo.

\[
X_t = \varepsilon_t + \theta \varepsilon_{t-1}, 
\qquad \varepsilon_t \sim \text{i.i.d. }(0,\sigma^2),
\]
la autocorrelación de primer orden se obtiene de la siguiente manera.

\textbf{Varianza}:
\[
\gamma(0) = \operatorname{Var}(X_t)
= \sigma^2(1+\theta^2).
\]

\textbf{Covarianza con el primer rezago}:
\[
\gamma(1) 
= \operatorname{Cov}(X_t, X_{t-1})
= \theta \sigma^2.
\]

\textbf{Autocorrelación de primer orden}:
\[
\rho(1) 
= \frac{\gamma(1)}{\gamma(0)}
= \frac{\theta \sigma^2}{\sigma^2 (1+\theta^2)}
= \frac{\theta}{1+\theta^2}.
\]

Para \(\theta = 0.8\):
\[
\rho(1) = \frac{0.8}{1 + 0.8^2}
= \frac{0.8}{1.64}

\vspace{0.5cm}

{\bf Para el proceso AR(1):}
\[
X_t = \phi X_{t-1} + \varepsilon_t,
\qquad \varepsilon_t \sim \text{i.i.d. } (0,\sigma^2), 
\qquad |\phi| < 1.
\]


\[
\gamma(0) = \operatorname{Var}(X_t).
\]
Usando la ecuación del modelo:
\[
X_t = \phi X_{t-1} + \varepsilon_t,
\]
obtenemos
\[
\gamma(0) 
= \operatorname{Var}(\phi X_{t-1} + \varepsilon_t)
= \phi^2 \operatorname{Var}(X_{t-1}) + \operatorname{Var}(\varepsilon_t)
= \phi^2 \gamma(0) + \sigma^2.
\]
Despejando:
\[
\gamma(0)(1 - \phi^2) = \sigma^2
\quad\Rightarrow\quad
\gamma(0) = \frac{\sigma^2}{1-\phi^2}.
\]

Autocovarianza:

\[
\gamma(1) = \operatorname{Cov}(X_t, X_{t-1}).
\]
Usando de nuevo el modelo:
\[
\gamma(1) 
= \operatorname{Cov}(\phi X_{t-1} + \varepsilon_t,\, X_{t-1})
= \phi\,\operatorname{Cov}(X_{t-1}, X_{t-1})
    + \operatorname{Cov}(\varepsilon_t, X_{t-1}).
\]
Como $\varepsilon_t$ es ruido blanco e independiente de $X_{t-1}$:
\[
\operatorname{Cov}(\varepsilon_t, X_{t-1}) = 0,
\]
por lo que
\[
\gamma(1) = \phi\,\gamma(0).
\]

Entonces la \textbf{autocorrelación de primer orden} es:
\[
\rho(1) = \frac{\gamma(1)}{\gamma(0)} = \frac{\phi\,\gamma(0)}{\gamma(0)} = \phi.
\]



De manera análoga, para $k \geq 1$:
\[
\gamma(k) = \operatorname{Cov}(X_t, X_{t-k})
= \operatorname{Cov}(\phi X_{t-1} + \varepsilon_t,\, X_{t-k})
= \phi\,\operatorname{Cov}(X_{t-1}, X_{t-k})
= \phi\,\gamma(k-1).
\]

Esta relación recursiva implica
\[
\gamma(k) = \phi^k \gamma(0), \qquad k = 0,1,2,\dots
\]
y, por tanto, la \textbf{función de autocorrelación} es
\[
\rho(k) = \frac{\gamma(k)}{\gamma(0)} = \frac{\phi^k \gamma(0)}{\gamma(0)} = \phi^k,
\qquad k = 0,1,2,\dots
\]

Es decir, en un AR(1) estacionario la autocorrelación de orden $k$ decae geométricamente como $\phi^k$.

No es necesario todo el calculo solo explicar porque la correlación con el  primer rezago es 0.8 y luego decrece. (3 puntos)

\item \textbf{(4 puntos)} Plantee el test de Breusch-Pagan para heterocedasticidad. Sabiendo que el $R_{aux}^2$ de la regresión auxiliar alcanza el valor de 0.1, ¿es posible afirmar que hay heterocedasticidad?

$$\hat{u}_i = \delta_0 + \delta_1 \cdot dist + \delta_2 \cdot auto + \delta_3 \cdot tele$$

Luego \textbf{(2 puntos)}, 

$$H_0: \delta_1 = \delta_2 = \delta_3 = 0$$
$$H_0: \text{al menos un } \delta_j \neq 0$$

Con la información del enunciado,e puede calcular el test LM que es equivalente a Breusch-Pagan de la forma \textbf{(1 punto)}:

$$LM: n R_{aux}^2 \sim \chi^2_{(k)}$$
$$LM: 450 \cdot 0.1 \sim 7.81$$

Como $45 > 7.81$, entonces se rechaza la hipótesis nula y se concluye que hay heterocedasticidad \textbf{(1 punto)}.}
